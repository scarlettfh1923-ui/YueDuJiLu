# New rendering dependency

AndroidLiquidGlass / Backdrop **1.0.4** — Kyant0.

- Source: https://github.com/Kyant0/AndroidLiquidGlass
- Documentation: https://kyant.gitbook.io/backdrop
- Coordinates: `io.github.kyant0:backdrop:1.0.4`
- License: Apache License2.0; included at `LICENSES/Backdrop-Apache-2.0.txt`.
- Used as a published, unmodified Android library for local background-layer sampling,
  blur, AGSL edge refraction, highlights and shadows. No external rendering service.
- We use1.0.4 to stay compatible with Compose1.10/Kotlin2.3. No AGP/Compose upgrade.
- This is an Android approximation, not Apple's proprietary Liquid Glass implementation.
