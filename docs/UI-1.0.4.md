## 已修缺陷

1. CameraX MLKit完成监听绑定了会关闭的worker。GMS Tasks隔离复现旧写法的晚完成/二次投递RejectedExecutionException；现在完成监听使用mainExec，图像分析仍独立worker，先clearAnalyzer再解绑本页用例并关闭。保留ORIGINAL与严格ISBN。
2. ISBN查询连接初始化和VM外层异常边界不足，取消/失败时busy可能遗留。现在连接初始化纳入边界，取消正常传播，finally复位；离开或新查询会取消旧请求，不被迟到结果导航回来。未知异常只显示类型，不回显可能含秘密的消息。
3. 环比毫秒直接转字符串。现在按指标单位输出中文时分秒/天/本/条，正负与持平均测试；未结束周期仅对比相同已过天数。
4. 同账号同日旧微信正值可能重复参与日期统计；统一选最新记录。null即使标complete也不当0；缺笔记字段不补零、不作完整比较。
5. 主动完读但没有计时的实体书，卡片与区间书单不一致；现在均包含，并仍保留475/500的主动完读页数。
6. 趋势图未知提示曾挤偏日期/条形基线，审图后改固定标记槽。历史周日历曾默认选今天（区间外），现在默认夹在区间内且外部日期淡显。
7. 极大卡片数字使用万/亿缩写，不以省略号掩盖；详情与语义仍保留原数。
8. 日历长区间投影避免每天重新拆全部会话；实体区间时长预聚合，不按每本书重扫所有会话。

98项测试通过，0失败/错误/跳过。55张生产Compose的API35 NATIVE/HWUI PixelCopy原生离屏PNG；含六详情各正常/窄屏大字、四主题书架与统计、历史周日历、空态/长标题/长数字与全部既有表单。64帧原生导航动画经审阅确认滑块连续、无越界裁切、图标文字对齐，直接切页无叠影；这不是设备帧率测量。
