# 书蠹 1.0.5 / v7 实现与覆盖计划

获批参考：`/workspace/reading-ui/controls-depth-v7/{01-shelf,02-stats,03-book-detail}.png`，对应HTML与design-decisions.md。不是v5书架或旧统计方案。

## 设计到原生组件
- 地面 / 组底 / 实底内容三层。青瓷背景#E2EBE5、内容#FAFCFA、控件#FCFEFC、组底#D5E2D8、工具#EDF4EE；其余三主题由各自调色板派生层次，不覆盖已有主题选择。
- Porcelain.kt集中实底短接触阴影与上左渐隐高光；outline、clip、shadow、点击区域共享Shape。普通22dp；胶囊50%（实际高度一半），不新增随意小圆角家族。此材质不是液态玻璃；底栏原有背景采样玻璃保持。
- BookRow：普通172dp最小高度、封面76×约116dp、内边距18、封面间距18、标题19/27sp、作者来源合并、3dp进度、视觉小阅读钮但触控至少48dp。长文字/大字自然增高。
- 统计：period/source/date独立22dp实底工具组、六卡134dp正常高度并随字体整行增加、12dp网格间距、固定数字基线槽、六种协调低饱和色。数据口径与点击详情不变。
- 书详情：居中标题+48dp以上返回/编辑，84×约128封面实底摘要，主继续阅读与补录/读完/弃读同一操作组。完读日期编辑保留；1.5字体三次操作允许等高自适应。不改475/500主动完读语义。
- MainTabs计算滚动末尾保留：实际字号底栏高度+计时浮条预算+系统导航安全区+间距，所有主页面共享。不靠固定巨大空白，也不让末项停在玻璃后。
- 不改底栏动画/主页面直接切页/扫描线程修复/持久化身份/主题ID/正式图标。无新依赖、无R8策略变化。

## 实图自审修正
- 360dp/1.5字体极长时长曾使“24.7万”的“万”被省略。已将数字受控自适应字号下限从16sp改为14sp（在1.5字体下实际至少21sp），单位与固定数字基线槽不变，完整原值仍在语义/详情中。新增断言直接检查TextLayoutResult无ellipsis/overflow，复核原生PNG确认“24.7万 小时”完整。
- “performScrollTo”只保证进入页面viewport，不知道浮动底栏。因此末项测试实际swipe到滚动末端，再断言整张末书卡在活动计时条上方，末统计卡和最后口径注释均在底栏上方；不能拿进入viewport假装避让已测。
- 这两项均为布局/测试修正，不改变统计数值算法或业务范围。
